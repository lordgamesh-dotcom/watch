# Cyberpunk HUD for Galaxy Watch

Resource-only Watch Face Format watch face for round displays, plus a small Android phone companion. The project is centered on the user-supplied Galaxy Watch 7 reference art and uses a 480 × 480 virtual canvas.

## Assumptions and compatibility

- WFF version 2 is selected because the requested Flavor presets require WFF 2. WFF 2 requires Wear OS 5 / API 34, so the watch face `minSdk` is 34; this supersedes the PDF's suggested `minSdk 33`, which is not compatible with its requested features.
- Android Gradle Plugin 9.5.1 and Gradle 9.6.0 are used as the latest stable releases verified for this workspace on November 5, 2026. The watch-face module disables built-in Kotlin (`enableKotlin = false`) and contains no custom app code; its manifest declares `hasCode=false`.
- The official WFF setup guide says watch-face bundles and app logic must be separate for store upload. The phone companion and face therefore have separate application IDs, both derived from `applicationIdBase` in `gradle.properties` (`com.example.cyberpunkface`).
- Watch-face Play target API is 35, matching the Play requirement for Wear OS apps effective August 31, 2026; the phone companion targets API 36 under the regular Android app requirement. Compile SDK is 36.
- Heart rate and steps are exposed as user-assignable complication slots. WFF 2 adds the heart-rate system source; `STEP_COUNT` is available as a system complication provider. Stress has no verified standard WFF source and is available only through the third slot. This project does not fabricate live readings.
- The watch face declares no health runtime permissions. Heart rate and step access is delegated to the selected system complication providers, which handle their own permission and data flow. A Samsung Health stress provider must be installed and authorized separately.
- The font files are Orbitron variable and Share Tech Mono, with their OFL license texts in `fonts/`; the WFF XML refers to those resources by family name.
- WFF 2 supports `Outline` for regular `Text`, but its `TimeText` font definition does not accept that decoration. The Galaxy Watch 7 AOD display offload also skipped both `Outline` text and `DigitalClock` in an on-device test; only plain `PartText` rendered. The AOD clock is therefore eight cyan `PartText` copies shifted by 1–2 px with a black copy on top, which simulates the outlined AOD reference. AOD groups are shown with a `Variant` on each top-level group. Device-level AOD power and burn-in behavior remains to be measured.
- WFF 2 limits each `ColorOption` to five colors. The six palettes use two linked configurations: `theme` carries roles 0–4 and `accent` carries roles 5–7. Flavor presets select the matching option in both configurations.
- Layout choices and requested settings/flavors are declared. RINGS is the composed layout. BARS changes the progress indicators to segmented bars; MINIMAL hides the indicator tracks. Complication slots remain in the same three-column positions in each layout, rather than reflowing to a row. Each slot draws one continuous progress arc (RINGS) or bar (BARS) from RANGED_VALUE value/min/max, GOAL_PROGRESS value/target, or a numeric SHORT_TEXT (heart rate over 180, stress over 100; `[COMPLICATION.TEXT]` is not coerced to a number on device, so up to three digits are parsed with `subText` comparisons). Non-numeric text such as `--` or `Estresse` shows `--`. Slots prefer the Samsung Health heart-rate, steps (GOAL_PROGRESS) and stress providers, with system fallbacks. The tick ring turns clockwise once per minute (`[SECOND] * 6` tweened by a 1 s, 60 fps clockwise `Animation`) and carries a yellow seconds marker with a fading trail, so the marker points at the current second; the corner arcs stay fixed. The clock supports follow-device, forced 12/24-hour, leading-zero, optional seconds and glitch toggles. The battery bar has ten slanted blocks driven by `[BATTERY_PERCENT]`: full blocks per 10%, a dimmed block for the current range. These items need on-device review before store release.
- The phone screen shows connection status through the Wearable NodeClient and gives the installation/customization and ADB instructions. The Play listing is not published, so a remote listing launcher is not shown.

## Retrowave face

`retrowave/` is a second resource-only watch face (application ID suffix `.retrowave`) with a vaporwave / Vice City neon-island scene: dark sky with twinkling stars, a half sun made of horizontal gradient stripes, two neon triangles that flicker now and then, a palm island whose palms sway, and dark water with a shimmering sun reflection. On top: a Monoton clock, an Audiowide date, a seconds marker on the rim, and heart-rate, battery and steps panels. Animations step on `[SECOND]` and are smoothed with `Animation` tweening, the approach that rendered smoothly on the Galaxy Watch. It has one setting, **Palette** (Neon Island, Vice City, Vaporwave). Its XML is generated by `scripts/generate_retrowave.py`; edit the script and re-run it instead of editing the XML by hand. The preview is an on-device capture with the system status icons removed and the date redrawn. AOD shows only the Monoton clock as plain `PartText`, because the Galaxy Watch AOD offload rendered only plain text in testing. Fonts: Monoton and Audiowide (OFL, licenses in `fonts/`).

Install it with `scripts/install.sh retrowave`.

## Wasteland Terminal face

`wasteland/` is a third resource-only watch face (application ID suffix `.wasteland`): an original retro-futuristic terminal design in the post-apocalyptic genre, not a copy of any licensed face (no third-party characters, logos or names). It has a phosphor CRT glow, scanlines with a rolling scan band, an occasional screen flicker, a VT323 clock with a blinking colon, a command-line date with a blinking cursor, an analog pulse gauge whose needle follows the heart-rate complication (40–200 bpm), a status panel (steps, battery, seconds), a 20-segment power bar, and a stepping seconds marker on the bezel. One setting, **Phosphor** (Green, Amber, Ice). Its XML is generated by `scripts/generate_wasteland.py`, which uses the shared helpers in `scripts/wfflib.py`. Font: VT323 (OFL). Install with `scripts/install.sh wasteland`.

## Build

Requires JDK 17 or newer and Android SDK platforms/build tools for API 35 and 36. In this workspace, JDK 21 and the Android SDK were available.

```sh
./gradlew :watchface:assembleDebug :retrowave:assembleDebug :wasteland:assembleDebug :phone:assembleDebug
./gradlew :watchface:assembleRelease :retrowave:assembleRelease :wasteland:assembleRelease :phone:assembleRelease
```

The debug face APK is `watchface/build/outputs/apk/debug/watchface-debug.apk`. The release build is unsigned unless a signing configuration is supplied; never commit signing credentials. Rename both package IDs by changing `applicationIdBase` in `gradle.properties`.

## Install on a watch

```sh
scripts/install.sh
```

For wireless ADB, enable Developer options and Wireless debugging on the watch, run `adb pair WATCH_IP:PAIR_PORT` with the pairing code shown by the watch, then `adb connect WATCH_IP:DEBUG_PORT`. Run the installer while connected and select Cyberpunk HUD from the watch face picker.

## Preview and validation

`scripts/render_preview.py` generates the 480 × 480 preview resource with Pillow. The supplied full-color image is retained as a separate visual reference in the phone resource tree.

`scripts/validate-wff.sh` validates `watchface.xml` against the vendored official WFF 2 schema with an XSD 1.1 processor (`uv run --with xmlschema`). The schema uses repeated `xs:all` groups that the libxml2 schema processor used by xmllint does not accept. To run Google's memory-footprint evaluator, build its official tool from the `google/watchface` repository as described in that repository's `play-validations/README.md`, then set `WFF_MEMORY_EVALUATOR_JAR` to the built JAR and run the script after assembling the debug APK. The evaluator measures APK asset memory, not rendering correctness.

## Unverified assumptions and known limitations

- Samsung's One UI Watch behavior for providers that expose stress data depends on the installed health provider and must be tested on a Galaxy Watch.
- A provider may return a RANGED_VALUE or SHORT_TEXT payload that differs in formatting; the face uses the slot's supplied value/text and shows `--` for an empty or non-numeric slot. The Samsung stress provider supports only ICON, SMALL_IMAGE and SHORT_TEXT, so the stress level label (BAIXO/NORMAL/MÉDIO/ALTO) is derived from its numeric text.
- The date uses `icuText` with the device locale, trimmed to three letters and uppercased (for example `SÁB // 07.NOV.26`). Small dynamic strings choose pt or en from `[LANGUAGE_LOCALE_NAME]`, because `[LANGUAGE_CODE]` was empty on the Galaxy Watch 7.
- `screencap` returns a black frame while the Galaxy Watch 7 is in AOD (display offload), so the AOD must be checked by eye. Samsung also leaves AOD immediately when the watch is off the wrist (`reason=offbody`).
- WFF 2 permits text outlines for ordinary `Text`; its `TimeText` font definition does not accept that decoration. AOD is thin dim Orbitron text instead.
- The supplied reference graphics show the target composition; the generated preview is representative and is not a screenshot from Wear OS.
- No Play listing exists. Companion-app cross-device launch to a Play listing should be wired after publication and a listing ID is available.
